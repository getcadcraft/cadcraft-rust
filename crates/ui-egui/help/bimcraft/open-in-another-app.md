## What you'll do

Carry on with a file in the app made for the next job, without saving it and opening it again.

## Steps

1. Open a DWG or DXF drawing to edit it in the drafting app, or an IFC model to detail it in the detailing app.
2. Click {{ui:Edit in CadCraft}} on the 2D view of a drawing, or {{ui:Open in DetailCraft}} in the toolbar of a model.
3. The other app opens in a new tab with the file already open.

## What you should see

- The file in the new tab. BimCraft keeps it open too.
- A model with unsaved changes goes over with those changes in it. Your own copy is not saved.
- A drawing goes over without its linked drawings.

## Good to know

- The file passes between the two tabs inside your browser. Nothing is uploaded.
- A button only shows when the other app is open where you are and can take a file this way.
- If nothing opens, the browser blocked the new tab: allow pop-ups for this site and click again.
