## What you will learn

What happens to a model while several people detail it at the same time. CadCraft Studio starts and joins the session (Share live, Join); this page is about the model itself.

## Everyone works at once

Add and edit members, connections, footings, stairs and bolts as usual. Your own edits show at once; other people's appear a moment after they make them.

- **Two people change one member:** different settings (one the profile, the other the end point) are both kept; the same setting goes to the later change.
- **A connection on a member someone just deleted** is taken back, and the status bar says why.
- Grids, levels and phases go to whoever changed them last.
- Built geometry, piece marks and the schedule are worked out in every window from the same model, so they agree.

## Undo undoes your own work

{{key:Mod+Z}} undoes your own last edit and leaves everyone else's alone. When someone changed the same thing since, nothing is undone and the status bar says who.

## Join from a browser

A teammate without Studio can scan the picture under the host's code with a phone, tablet or computer on the same network. DetailCraft opens in the browser and fills with the host's model once the host lets you in. Invite links, for joining from another network, are not open yet.

## When the session ends

Only the host saves the model. Everyone else keeps an unsaved copy: save it if you want to keep it.
